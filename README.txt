تشغيل Sales Control على HTTPS (مجاني) — GitHub Pages
1) افتح github.com ← New repository (اسمه مثلاً sales-control) ← Add file ← Upload files
2) ارفع كل الملفات الموجودة في هذا الفولدر (index.html و manifest.webmanifest و sw.js و الأيقونتين) ← Commit
3) Settings ← Pages ← Source: Deploy from a branch ← main / root ← Save
4) بعد دقيقة الرابط يكون: https://USERNAME.github.io/sales-control/
5) على التابلت (Chrome): افتح الرابط ← قائمة ⋮ ← Install app / Add to Home screen. (آيباد: Safari ← مشاركة ← Add to Home Screen)

تنبيه أمان: الريبو العام يعني أن ملف index.html (وفيه بيانات المبيعات) يقدر أي شخص معه الرابط يقرأه.
للحماية المجانية استخدم Cloudflare Pages + Cloudflare Access (مجاني حتى 50 مستخدم، دخول بإيميل + كود).
